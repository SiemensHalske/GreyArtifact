Hilfe & Begriffe

Die wichtigsten Begriffe in GreyArtifact und wie sie zusammenhängen.

Überblick

So hängt alles zusammen

  1. ABArbeitsbereichWer Zugriff hat und mit welcher Rolle
  2. PRProjektEin Vorhaben, zum Beispiel ein Kunde
  3. IMImportRohdatei, unverändert gespeichert
  4. ASAssets & FindingsAbgeleitet, mit Herkunft
  5. BWBewertungStatus, Notizen, ML-Feedback

EN Recon-Runs starten nur innerhalb eines gültigen Engagements mit Autorisierung, Zeitraum und Scope.

Zugriff

{% call term("arbeitsbereich", "Arbeitsbereich", "AB") %}Oberste Ebene für Zugriff und Rollen. Mitglieder sehen nur die Arbeitsbereiche, in denen sie eine Rolle haben.{% endcall %} {% call term("rollen", "Rollen", "RO") %}Viewer liest Daten; Researcher importiert und löscht zusätzlich; Analyst verwaltet zusätzlich Projekte; Owner verwaltet außerdem Mitglieder, Rollen und den Arbeitsbereich: Konten anlegen, sperren, Passwörter neu setzen und Mitglieder entfernen. Der letzte aktive Owner kann weder herabgestuft noch gesperrt oder entfernt werden.{% endcall %}

Daten & Evidenz

{% call term("projekt", "Projekt", "PR") %}Sammelt Importe, Assets, Findings und Recon-Läufe zu einem Vorhaben, zum Beispiel einem Kunden.{% endcall %} {% call term("import", "Import / Rohartefakt", "IM") %}Eine hochgeladene Datei bleibt unverändert gespeichert und wird über ihren SHA-256-Hash eindeutig identifiziert. Daraus werden Assets und Findings abgeleitet.{% endcall %} {% call term("asset", "Asset", "AS") %}Ein normalisiertes Ziel: Domain, IPv4- oder IPv6-Adresse, URL oder Service. Gleiche Werte werden zusammengeführt.{% endcall %} {% call term("evidenz", "Evidenz / Herkunft", "EV") %}Zu jeder Eigenschaft, jeder Beziehung und jedem Finding ist gespeichert, aus welchem Rohartefakt es stammt.{% endcall %} {% call term("sensible-rohartefakte", "Sensible Rohartefakte", "SR") %}Rohdateien, die Geheimnisse enthalten können; ihr Download erfordert eine eigene Berechtigung.{% endcall %}

Findings

{% call term("finding", "Finding", "FI") %}Ein Befund, derzeit aus Nuclei-Importen, mit Schweregrad und Status (Neu, Bestätigt, False Positive, Behoben, Akzeptiert). Statuswechsel und Notizen werden nur angehängt, nie überschrieben.{% endcall %}

Recon

{% call term("engagement", "Engagement", "EN") %}Hält fest, was geprüft werden darf: Nachweis der Autorisierung, Zeitraum, erlaubte und ausgeschlossene Domains.{% endcall %} {% call term("recon-run", "Recon-Run", "RR") %}Ein kontrollierter Lauf des festen Profils domain_basic_v1 innerhalb eines gültigen Engagements, ausgeführt in einem vom Webserver getrennten Runner.{% endcall %}

ML & Fennec

{% call term("fennec-lauf", "Fennec-Lauf (Import-Batch)", "FL") %}Ein Paket aus der Fennec-Pipeline mit Manifest, Vorhersagen, Beobachtungen und optional Claims; jede Datei wird per SHA-256 geprüft.{% endcall %} {% call term("ml-vorhersage", "Rang und Perzentil", "RP") %}Die Reihenfolge, in der Assets eines Laufs gesichtet werden sollten: Rang 1 bzw. Perzentil 100 ist am auffälligsten. Keine Wahrscheinlichkeit für einen Angriff oder eine Schwachstelle.{% endcall %} {% call term("modellstatus", "Modellstatus", "MS") %}Kandidat (nicht validiert), Validiert, Freigegeben oder Ausgemustert. Nur validierte und freigegebene Modelle haben die Qualitätsprüfung bestanden.{% endcall %} {% call term("bewertung", "Bewertung", "BW") %}Erwartbar, Datenartefakt, Prüfenswert oder Bestätigter Befund. Bewertungen werden an Fennec zurückgespielt; eine Vorhersage wird nie automatisch zum Finding.{% endcall %} {% call term("claim", "Claim", "CL") %}Eine Aussage über eine Domain, etwa „öffentlich erreichbar“, mit Belegen dafür und dagegen; Zustände: gestützt, widerlegt, unbekannt, zu wenig Belege. Vorschläge zur weiteren Erhebung werden nur angezeigt, nie ausgeführt.{% endcall %}

Betrieb

{% call term("systemstatus", "Systemstatus", "ST") %}Live-Prüfung von Anwendung, Datenbank, Speicher, Backup, Zertifikat, DynDNS und Plattenplatz; nur für Owner und Admins.{% endcall %}

Kein passender Begriff. Versuch es mit einem anderen Stichwort.
